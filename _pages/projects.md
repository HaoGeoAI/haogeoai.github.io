# Projects

## CameraTrap-Instruct

A vision–language framework for structured ecological interpretation of camera trap imagery.

**Methods:** VLMs, LoRA, multimodal projector alignment, camera trap image analysis  
**Applications:** Species identification, instance counting, behavior classification, OCR-based metadata extraction, ecological reasoning

---

## Thermal VLM Adaptation for Drone-Based Wildlife Monitoring

A lightweight adaptation framework for applying RGB-pretrained vision–language models to thermal drone imagery.

**Methods:** Thermal remote sensing, VLM adaptation, LoRA, multimodal projector alignment  
**Applications:** Wildlife species recognition, instance counting, aerial conservation monitoring

---

## Multi-Perspective Wildlife Monitoring Using Drones and Camera Traps

An integrated monitoring framework combining drone thermal imagery and camera trap data for spatial analysis of wildlife distributions and human–wildlife interactions.

**Methods:** YOLO detection, KDE, IDW, camera traps, drone remote sensing  
**Applications:** Conservation planning, wildlife monitoring, human–wildlife interaction analysis
